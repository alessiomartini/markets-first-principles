physics: "A collective variable: a few common modes that explain most of the covariance of many individual assets."
---

A common source of return to which many assets are exposed, such as the market, company size, value or momentum. Factor models write each asset's return as exposures to a small number of factors plus a residual, which cuts the number of parameters in the covariance matrix. Whether a factor earns a persistent premium, and why, is a separate and often disputed question.
